## Recurring needs

- Turn messy documents and spreadsheets into structured outputs with arithmetic
  checks, traceable source rows and understandable exceptions.
- Keep operators in control of draft vouchers, workbook changes and ERP actions.
- Make scheduled collection, reporting and delivery observable and recoverable.
- Improve useful discovery, personalization and simple rating controls.
- Evaluate agent reliability, coordination, cost and local Windows workflows.

## Editorial rules

Exclude GHADC and its portal from recommendations in both newsletters, including
when historical editions mention it. Past editions are historical records.
Use all eligible repositories for relevance, without requiring an item for every
repository in each seven-item edition. The newest repositories deserve attention
when a source solves a documented need.

Use sanitized summaries only: no private code excerpts, client records, account
details, positions, invoices, workbooks or credentials in research queries.
Every suggested application remains a proposal to test with synthetic or approved
data. Clearly distinguish planning projects and unreviewed repositories from
implemented software. Prefer concrete user benefits, five adoption steps and
primary-source evidence; preserve original dates and publication requirements.
