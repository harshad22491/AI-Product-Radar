# AI Product Radar

AI Product Radar is a private, personalized daily newsletter and Obsidian knowledge base for practical AI products, tools, techniques, and research that can improve the owner's software portfolio.

The system is designed to:

- deliver at least seven plain-language findings every day at 17:00 Asia/Kolkata;
- explain each finding with a concrete example from an existing repository;
- learn from item-level 1–5 ratings without confusing preference with credibility;
- review owned public and private GitHub repositories every ten elapsed days, read-only;
- use Claude Fable 5.1 subscription access as the primary researcher, GPT-6 Astra for validation and repository analysis, then Opus and Sol as fallbacks;
- use private Google Drive bundles, Google Sheets, Forms, Apps Script, and Gmail for free cloud state and delivery;
- synchronize the cloud record into a separate local Obsidian vault when Windows is online.

Scheduled execution does not run on GitHub Actions. Private research records and customer material do not belong in Git.
