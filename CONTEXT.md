# Domain glossary

## Finding

A source-backed product, tool, technique, release, or research result selected for possible use in the owner's work.

## Item

The permanent record of one Finding. It has a stable ID shared by email, cloud state, conversations, and Obsidian.

## Digest

The dated collection delivered at 17:00 Asia/Kolkata. It normally contains seven Items and never invents or disguises filler to meet that count.

## Useful discovery

A previously unfeatured Item used on a quiet day. Academic sources may be at most two years old; every other source may be at most six months old.

## Rating event

An immutable statement that assigns an Item a score from 1 through 5, with an optional reason, origin, and revision. Corrections create new events.

## Current rating

The latest unambiguous Rating event for an Item. Ratings change personal relevance, never factual credibility.

## Experiment proposal

A read-only implementation suggestion created from a five-star Item. It describes scope, effort, expected value, risk, and verification without modifying a target repository.

## Repository profile

A dated, evidence-backed and sanitized description of an owned GitHub repository. It excludes credentials, customer documents, financial records, generated reports, workbooks, and raw transactions.

## Incremental review

A read-only examination of repository changes since the last successful cursor. It becomes due ten elapsed days after the last complete review.

## Run bundle

An immutable JSON and Markdown package produced by a scheduled model. Google Apps Script validates a bundle before it can update canonical state or trigger delivery.

## Canonical record

The logical current state reduced from immutable Run bundles and Rating events. Google Sheets is the cloud index; the Obsidian Item note is the user-facing synchronized representation.
